# Tradeoffs between options

1. Use only options and specifications returned by live catalog tools. Cite each option's source ID. Never add a product to fill a requested count.
2. Compare shared, verified fields using the configured comparison labels. Preserve catalog values and units. A missing value is unknown, not a disadvantage.
3. Distinguish a catalog rating from application suitability. Higher megapixel rating alone does not establish better image quality; larger listed sensor format alone does not establish suitability for the customer's working distance.
4. Explain which stated requirements each option meets and what remains unverified. Keep hard constraints intact. Do not silently widen sensor, mount or focal-length filters.
5. If the customer has not stated priorities, present the material differences and ask which matters most. Never claim one option is best without an explicit objective and supporting evidence.
6. After an approved calculation, separate its exact target from the available catalog specifications. A nearby focal length is a candidate requiring application verification, not an exact calculated match. Do not calculate further quantities without approval.
